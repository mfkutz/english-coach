# JobCoach — Landing Page

Sitio de marketing para **JobCoach**, el coach de inglés profesional para personas que trabajan (o quieren trabajar) en empresas internacionales.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v3
- lucide-react

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
